# PlateBack

PlateBack lets bakeries, cafes and restaurants list end-of-day surplus food, and lets people nearby reserve it and collect it during a short pickup window with a pickup code. YuvaIntern programme project.

| [`frontend/`](frontend/) | React frontend (Week 2). Setup, design, accessibility and testing notes are in its [README](frontend/README.md). |

## Week 2 submission

The ZIP of the frontend source is attached to the [latest release](https://github.com/mhrjnrahul/PlateBack---Frontend/releases/latest).

## Run it locally

Requires Node.js 22.22 or newer.

```bash
cd frontend
npm ci
npm run dev
```

No backend is needed: a mock API runs in the browser. Demo accounts are listed in the [frontend README](frontend/README.md#demo-accounts).

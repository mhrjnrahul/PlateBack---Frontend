# Listing photos

the category illustration (`CategoryIllustration.tsx`), so the app works with
none of them.

- JPEG, 4:3 crop, 1200 × 900 px, under 200 kB
- Food only: no people, no text or logos on the photo
- Only use photos you have the rights to (your own, or a licence that allows it)
